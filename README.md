# CYBER-LAN SUPER SUITE v3.0 (ULTIMATE EDITION) 🚀

منصة المعمل المتكاملة بتصميم الهاكرز (Cyberpunk / Modern Discord):
شات محلي، قاعدة بيانات، سينما متزامنة للأفلام، ألعاب جماعية، ومشاركة ملفات بدون إنترنت وبدون سيرفر وسيط.

---

## 🌟 الميزات الجديدة في الإصدار v3.0:

1. **قاعدة بيانات محلية (SQLite Database):**
   - حفظ تلقائي لكافة المحادثات (العامة، المجموعات، الرسائل الخاصة).
   - حفظ البروفايل (الاسم، الأفاتار، البايو) ليبقى دائماً محفوظاً عند فتح البرنامج في أي وقت.

2. **قسم الألعاب الجماعية والبث (Games Arena & Spectator):**
   - **لعبة X-O (Tic-Tac-Toe):** تحدي ثنائي مع رصد الفائز تلقائياً.
   - **لعبة السلم والتعبان (Snakes & Ladders):** تدعم من لاعبين حتى 4+ لاعبين مع رقعة الـ 100 مربع ونرد متحرك.
   - **وضع المشاهدة (Spectator Mode):** أي شخص على الشبكة يستطيع الدخول لمشاهدة أي جيم نشط في الوقت الفعلي!

3. **مسرح مشاهدة الأفلام المتزامن (Watch Party Theater) 🎬:**
   - بث الأفلام ومقاطع الفيديو عبر سيرفر وسائط محلي فائق السرعة.
   - تشغيل متزامن لحظياً (Play / Pause / Seek) لجميع الأجهزة لمشاهدة نفس اللقطة في نفس الثانية!
   - شات جانبي مدمج (Side-by-Side Chat) للتعليق أثناء مشاهدة الفيلم.

4. **المجموعات (Groups Hub):**
   - إنشاء غرف وقنوات مخصصة (مجموعات دراسية، جيمنج، مشاريع).
   - شات خاص بكل مجموعة وحفظ رسائلها وسجلاتها.

5. **القصص اليومية (24h Ephemeral Stories):**
   - نشر Status يظهر كدوائر بالأعلى لجميع أجهزة المعمل ويختفي تلقائياً بعد 24 ساعة.

6. **محرك الـ Streaks وقواعد عطلة نهاية الأسبوع:**
   - احتساب استمرار التفاعل اليومي بالـ `🔥 Streak`.
   - قاعدة الـ 24 ساعة للتفاعل، مع **تجميد الحساب تلقائياً يومي الجمعة والسبت** حتى لا ينكسر الاستريك أثناء العطلة!

7. **مشاركة الملفات ومكتبة الاستيكرز (Media Vault):**
   - دعم إرسال ملفات Office (`.docx`, `.pdf`, `.pptx`) والفيديوهات والصور.
   - مكتبة استيكرز مع زر `[ ➕ Add to Favorites ]` لإضافة أي صورة من جهازك للمفضلة بضغطة زر.

8. **زر الهروب السريع والتخفي (Boss-Key F12):**
   - إخفاء الواجهة فوراً وفتح مذكرة فيزياء براءة بنقرة واحدة على `F12`.

9. **صلاحيات الأدمن (`192.168.20.54`):**
   - رتبة `👑 ROOT ADMIN` مع شريط تحكم بمسح الشاشات وإسكات الغرفة.
